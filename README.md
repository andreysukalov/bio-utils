# Bio Utils
A lightweight utility for processing biological sequences. It focuses on sequence data extraction and filtering. The project follows a modular design philosophy to keep its components lightweight, reusable and compatible.
## Instalation
Clone the repository from GitHub and navigate to the project directory:
```bash
git clone -b HW4 https://github.com/andreysukalov/bio-utils.git
cd bio-utils
```
Check the installed Python version:
```bash
python --version
```
## Dependencies
Python(the scripts were developed using Python 3.14.8)
